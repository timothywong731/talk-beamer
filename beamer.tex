\section{Business Requirements and Context}
\begin{frame}
\frametitle{Business Requirements and Context}
Migrating enterprise applications to the cloud means \textbf{understanding them
first}!

\vspace{0.1cm}
\begin{block}{\small The challenge}
{\footnotesize
\begin{itemize}\setlength\itemsep{2pt}
  \item \textbf{\color{earlblue}Massive legacy estate:} \colorbox{earlblue!15}{millions of lines of code}, decades in the making.
  \item \textbf{\color{earlblue}Scarce knowledge:} documentation is thin or outdated, and app-team experts have often left.
  \item \textbf{\color{earlblue}Slow discovery:} mapping dependencies and risks by hand takes \colorbox{earlblue!15}{weeks} per app.
\end{itemize}
}
\end{block}

\vspace{0.15cm}
\footnotesize
\begin{itemize}\setlength\itemsep{1pt}
  \item \textbf{Discovery:} group the code and documents into logical components. \textit{(Output: a map of the system.)}
  \item \textbf{Deep Analysis:} assess each component's migration readiness, in parallel. \textit{(Output: per-component findings.)}
  \item \textbf{Enterprise Context:} apply organisational security and cloud standards. \textit{(Output: policy-aligned recommendations.)}
  \item \textbf{Readiness Questionnaire:} answer a standard cloud-readiness questionnaire. \textit{(Output: structured answers.)}
  \item \textbf{Reporting:} consolidate and review all findings. \textit{(Output: the final assessment report.)}
\end{itemize}

\section{Agent Memory}
\begin{frame}
\frametitle{Agent Memory}
\small
\begin{columns}[T]
\begin{column}{0.5\textwidth}
  \textbf{Shared long-term memory}
  \begin{itemize}\setlength\itemsep{1pt}
    \item A single shared memory accumulates findings across the whole run.
    \item Each phase reads what earlier phases discovered and writes back its own results.
    \item Later phases build on earlier work instead of re-reading the raw inputs.
  \end{itemize}
\end{column}
\begin{column}{0.5\textwidth}
  \textbf{Passing context between phases}
  \begin{itemize}\setlength\itemsep{1pt}
    \item The pipeline is serial: every phase produces a report.
    \item Each report, with the shared memory, becomes the input context for the next phase.
    \item By the final phase, agents reason over the full accumulated picture.
  \end{itemize}
\end{column}
\end{columns}
