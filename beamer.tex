\section{Agents' Memory}
\begin{frame}
\frametitle{Agents' Memory}
\small
\begin{columns}[T]
\begin{column}{0.5\textwidth}
  \textbf{Shared long-term memory}
  \begin{itemize}\setlength\itemsep{1pt}
    \item A single shared memory accumulates findings across the whole run.
    \item Each phase reads what earlier phases discovered and writes back its own results.
    \item Later phases build on earlier work instead of re-reading the raw inputs.
  \end{itemize}
\end{column}
\begin{column}{0.5\textwidth}
  \textbf{Passing context between phases}
  \begin{itemize}\setlength\itemsep{1pt}
    \item The pipeline is serial: every phase produces a report.
    \item Each report, with the shared memory, becomes the input context for the next phase.
    \item By the final phase, agents reason over the full accumulated picture.
  \end{itemize}
\end{column}
\end{columns}

  \begin{itemize}\setlength\itemsep{2pt}
    \item \textbf{File access:} browse and read the codebase and documents.
    \item \textbf{Knowledge retrieval:} ask questions over indexed documents; answers cite their sources.
    \item \textbf{Enterprise knowledge:} search organisational guidance (security, cloud, DevOps standards).
    \item \textbf{Diagrams:} create, validate and fix architecture diagrams, rendered offline.
  \end{itemize}
\end{column}
\begin{column}{0.5\textwidth}
  \textbf{How agents use them}
  \begin{itemize}\setlength\itemsep{2pt}
    \item Each agent is given only the tools relevant to its task.
    \item Tools turn raw inputs into structured, grounded findings.
    \item Grounded retrieval keeps answers anchored to real evidence.
    \item Tool use is logged for observability and cost tracking.
  \end{itemize}
\end{column}
\end{columns}

  \item \textbf{Discovery:} group the code and documents into logical components. \textit{(Output: a map of the system.)}

  \item \textbf{Readiness Questionnaire:} answer a standard cloud-readiness questionnaire. \textit{(Output: structured answers.)}
  \item \textbf{Reporting:} consolidate and review all findings. \textit{(Output: the final assessment report.)}
\end{itemize}

\end{center}
\vspace{0.2cm}
\begin{itemize}\setlength\itemsep{2pt}
  \item \textbf{Flow:} users upload through the web UI; the API stores inputs and queues a job; a worker then runs the phase pipeline.
  \item \textbf{Shared services:} the worker draws on storage, the search index and the model service to complete each phase.
  \item \textbf{Isolated environment:} the system runs fully offline, with automatic retries on transient failures.
\end{itemize}
\end{frame}
